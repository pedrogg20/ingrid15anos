# Projeto Ingrid 15 Anos

Site de celebração de 15 anos com navegação entre páginas.

## Estrutura

- **index.html** - Página inicial com imagem e link para o vídeo
- **dois.html** - Página com vídeo de 5 segundos
- **tres.html** - Página final com links de localização e WhatsApp

## Tecnologias

- HTML5
- CSS3
- JavaScript
